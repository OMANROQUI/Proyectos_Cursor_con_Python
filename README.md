# Proyectos Cursor con Python

Este repositorio contiene **ejercicios y mini-proyectos en Python**, organizados por carpeta. Cada carpeta incluye uno o más scripts (`.py`) enfocados en un tema/ejercicio específico.

## Estructura de la carpeta

- **`Analisis_Datos/`**: script de análisis de datos.
  - Archivo principal: `analisis.py`
- **`calculadora simple/`**: calculadora básica.
  - Archivo principal: `calculadora.py`
- **`contador_palabras/`**: contador de palabras (procesamiento de texto).
  - Archivo principal: `contador.py`
- **`Factorial/`**: cálculo de factorial.
  - Archivo principal: `prueba.py`
- **`Fizzbuzz/`**: ejercicio clásico de FizzBuzz.
  - Archivo principal: `fizzbuzz.py`
- **`Numero_Primo/`**: verificación/cálculo relacionado con números primos.
  - Archivo principal: `primo.py`
- **`Numeros_Naturales_Cuadrados/`**: ejercicios con números naturales y sus cuadrados.
  - Archivo principal: `ejercicio_autocompletar.py`

## Requisitos

- **Python 3** (recomendado 3.10+)

## Cómo ejecutar

Desde la raíz del proyecto, ejecuta el script que quieras. Ejemplos:

```bash
python3 "Fizzbuzz/fizzbuzz.py"
python3 "calculadora simple/calculadora.py"
python3 "Analisis_Datos/analisis.py"
```

## Notas

- La carpeta `.git/` contiene el historial del repositorio.
- El `.gitignore` excluye cachés de Python (`__pycache__/`, `*.pyc`) y carpetas típicas de editores (`.vscode/`, `.idea/`).
